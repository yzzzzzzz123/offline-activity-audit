# 类型识别与资料审核

先按本包实际资料角色逐项对照PDF八套清单，名称和费用项目名不定类。每类保存完整清单比对、条件和全部来源，以及清单外资料项。

资料项必须刚好等于对应PDF清单，缺项、多项或资料适用条件不明均classification_failed；唯一严格匹配才进入Skill。同一资料项的多页合同、多张照片合并计项，PDF例外照原文。只有结算单和POS的包必须失败。

分类失败对外只写“核销方式无法确认”，不展示逐类比对长说明；完整匹配明细保留在技术档案。

审核只执行本类型及PDF明列的适用通用要点，每项一次、不多不少；条件例外不能随意免除或加严。不得在现有要点中夹带其他检查。资料存在后的签章、水印、金额等问题按原文标准审核。

系统读取或模型故障保留为系统执行失败，不写成客户缺资料；已保存旧档案保持不变。
