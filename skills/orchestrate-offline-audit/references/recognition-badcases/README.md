# 图片识别纠错案例库

已收集六例：两例水印时分、一例水印年份、一例手写抬头、两例红章叠印或旋转误读。

`catalog.json` 保存错误转录、人工确认文本、读取要点、来源定位和原件SHA256。`originals/` 保存原件完整字节；PDF旁的PNG只作查看预览，明确标为派生文件。客户原件默认不进入Git。

运行时会先将已确认案例的文字纠错对及读取要点放入当前原图的读取提示，再按本单模型快照逐图读取；不会另发付费学习请求。这里的学习是提示内示例参考，不是微调，也不表示案例原图已发给模型。参考不是当前核销单证据，不复制示例公司、日期、金额或审核结论。

案例内容及版本进入完整读取提示和图片事实缓存身份。更新案例或更换推理强度后，不复用不相容的旧事实；保持每请求最多一张当前原图。

新增案例须有人工核验文本、实际原件及校验值。尚未核验的猜测不进入正式读取参考。历史核销记录和模型原回答保持原样，真实模型识别效果须另行实测。
