# PDF审核栏摘录与范围

仅摘录《费用核销类型-资料与标准清单-20260918.pdf》第1页八类“审核要点/标准”栏，统一排版标点；不混入资料栏、页首或业务背景。原PDF为最终文字依据。

## 人员激励

1. POS必含5+2项：活动时间、69码、商品名称、销售数量、销售单价、销售金额（数量×单价）、销售金额及数量合计；缺项即不完整。①活动申请69码单价与结算单奖励单价一致；②结算单每个SKU销售数量与POS对应销售数量一致；③结算单本次核销金额小于等于申请金额。
2. 红包无品牌公司名称（大额红包>1000元要求写公司名称）、金额与核销不一致 → 缺资料。
3. 临促少任意一天照片 → 缺资料。
4. 数量、单价填错 → 直接0核销。

## 陈列堆头

1. 水印二要素（拍摄日期：执行周期内；地址：活动门店地址一致），缺一即不完整。
2. 申请的堆头或者陈列大小范围里面只能存在参半的品牌，不允许有其他的产品。
3. 堆头陈列物料元素必须是小阔集团产品（参半、重点、小箭头）。
4. 中庭活动无入场协议 → 缺资料（勤策补充字段）。
5. 结算单非统一模板或未盖章 → 缺资料。
6. 数量、单价等明细与申请填错 → 直接0核销。
7. 按照申请的堆头大小与照片进行判断是否符合，由AI判断。

## KT板等物料制作

1. 发票抬头非经销商公司、无明细金额开票时间 → 缺资料。
2. 无成品照 → 缺资料。
3. 结算单非统一模板或未盖章 → 缺资料。

## 搭赠

1. POS必含5+2项：活动时间、69码、商品名称、销售数量、销售单价、销售金额（数量×单价）、销售金额及数量合计；缺项即不完整。①活动申请69码单价与结算单奖励单价一致；②结算单每个SKU销售数量与POS对应销售数量一致；③结算单本次核销金额小于等于申请金额。
2. 照片与小票均无、关键信息缺失 → 缺资料。
3. 数量、单价填错 → 直接0核销。

## 补差

1. POS必含5+2项：活动时间、69码、商品名称、销售数量、销售单价、销售金额（数量×单价）、销售金额及数量合计；缺项即不完整。①活动申请69码单价与结算单奖励单价一致；②结算单每个SKU销售数量与POS对应销售数量一致；③结算单本次核销金额小于等于申请金额。
2. 满减返还：另需现场水印照片、小票等活动存在证明，无证明 → 缺资料。
3. 门店照片缺水印、活动价格不清晰 → 缺资料。
4. 数量、单价填错 → 直接0核销。

## 进场费（原PDF名称；系统统一称条码费）

1. 推广协议非统一模板、未双方盖章 → 缺资料。
2. 照片无法辨识具体SKU与活动申请一致 → 缺资料。
3. 水印：门店地址要一致（存量要去检查是否重复）。

## 外采赠品

1. 赠送规则未备注 → 缺资料。
2. POS必含5+2项：活动时间、69码、商品名称、销售数量、销售单价、销售金额（数量×单价）、销售金额及数量合计；缺项即不完整；按照赠送规则赠送赠品数量。
3. 根据门店提供全量成品水印照片，包含外采赠品 → 缺资料。
4. 结算单未盖章、合同未签章 → 缺资料。
