# 大表读取边界

先运行本Skill入口的`--check`查看当前支持格式和真实资源边界，不凭经验承诺无限容量，也不直接调大安全阈值。

- 正常上传按存储单元格流式扫描，实际数据超过Excel声明范围时仍保留；仅格式把范围撑到百万行时不展开空矩形。
- 销售工具按顺序游标读取，同行各字段共享当前行；只缓存当前行，不逐格重扫整表。销售汇总不在一万行处截断。
- 全部工作表及其合计分别核对；不同Sheet、文件的同一行号不混合。完整POS复算由代码完成，模型只接收当前所需事实及程序结果。
- 表块按行保留完整事实，版式只带当前相关范围；表内图片关系用流式XML定位，逐张留下来源，不因表大改成抽样。
- 超长单元格不任意截字，公式与缓存分开；无缓存、错误值及无法确定的列保持原始事实，不能反推补数。
- 读取索引只在整体成功后发布；磁盘、权限、解压或解析资源故障保留具体阶段，不写成客户缺件。中断后的已验证审核阶段沿用现有断点协议，读取工具不自动重跑业务或回调。
