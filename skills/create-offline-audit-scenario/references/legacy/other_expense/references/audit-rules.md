# 其他费用审核规则

## 1. 适用边界

“其他费用”只适用于资料实质无法归入下列现有费用类型的新费用：

- 赠品：公司形象品、小样；
- 陈列堆头：地堆、陈列、专架、端架，以及商场中庭大面积展示所发生的场地使用费；
- 人员激励：人员报酬、销售提成、培训费用；
- 海报/物料制作：海报制作、海报张贴、宣传单页、展示道具、客户自采赠品物料；
- 维护费用；
- 补差；
- 搭赠；
- POS 达标激励；
- 进场费或条码费。

外层 ZIP 名中的“其他”、结算单中的“市场费用”或合同中的宽泛“活动费用”均不能单独证明新类型。先按合同、结算单、协议、发票/收据及活动证明中实际可见的费用描述进行分类。

如果一个包同时包含多个已知类型，逐项指出可归入的现有类型，并要求按相应类型重新提交或拆分；不得借“其他费用”绕过原类型规则。已知类型与未知类型混合时，已知部分回原类型，未知部分另行申请特殊审批。

## 2. 特殊审批门槛

确实无法归类的新费用，必须提供独立、可追溯的特殊审批证明。审批证明至少应清楚显示：

- 被批准新增的费用类型名称；
- 审批主体或审批人；
- 明确的批准意思表示；
- 可识别的审批日期；
- 签字、盖章或系统审批完成标记之一。

普通促销合同、结算单、付款申请、聊天说明或压缩包命名不替代特殊审批。审批证明缺失、未指明新类型或只有申请没有批准时，结论为“需特殊审批”，自动建议核销金额为 0。

## 3. 基础核销资料

通过特殊审批门槛后，仍须逐项检查：

1. 根据具体费用实质提供合同、协议、相关文件，以及活动周期内的活动照片、POS 数据、发票/收据或其他能证明费用发生和活动执行的材料。具体组合由新类型的审批口径决定；至少要有一份独立于促销合同和结算单的支持材料。
2. 同时提交公司统一模板的结算单，且必须有客户盖章。结算单应能识别客户、费用明细、计算方式、金额和结算日期；仅有“市场费用”等笼统总额不能覆盖具体类型。
3. 提交签章后的促销合同。合同应能识别签订方、活动内容、活动周期、费用构成或预算以及签章。

活动照片只能证明照片中可见的执行事实；文件名和 EXIF 不能替代可见水印。POS 只能证明其可见的销售期间、商品、数量和金额，不自动证明特殊审批或费用类型。

## 4. 权威关系

- 合同和支持协议说明费用发生的业务范围；
- 特殊审批只授权新增类型，不能补造合同、结算单或执行事实；
- 结算单是申报金额来源；
- 支持材料证明具体费用事实，不能只凭总额相同建立对应关系；
- 后提交的照片、POS、发票或收据不能静默修复缺失的审批、签章或客户盖章。

## 5. 金额与结论

申报金额取公司统一结算单明确列示的合计。合同或审批文件明确列示金额时，只做精确一致性检查；禁止用总额倒推单价、数量或费用构成。

其他费用属于人工特殊审批通道，系统不自动建议通过金额：

- 能归入现有类型：`类型归类错误`，自动建议金额 0；
- 无法归类但缺少有效特殊审批：`需特殊审批`，自动建议金额 0；
- 审批已完成但基础资料缺失或冲突：`资料需补正`，自动建议金额 0；
- 审批和资料均完整：`待人工核定`，仍保持自动建议金额 0，由有权审批人确认新增类型及金额。

## 6. 错误归因与补交

执行[统一错误原因与处理方式规范](../../../../../orchestrate-offline-audit/references/error-reasons.md)：错误原因只写具体问题文件、必要对照值、缺失字段或差异；建议只写处理方式。涉及的业务文件区域仅列相关实际文件 basename，不用整包清单兜底或展开证据。不得输出“资料无法逐一确认”一类没有来源的描述。

- 类型归类错误：列出显示已知费用描述的合同、结算单或协议，并写明应归入的现有类型；
- 特殊审批缺失：确认缺件时，原因只写“未提交批准新增费用类型的特殊审批证明”；补交该审批文件只写处理方式；已有用途未明资料时，不把未识别写成未提交；
- 结算单问题：指出结算单文件，以及缺失的统一模板特征、客户盖章、明细、金额或日期；
- 促销合同问题：指出合同文件，以及缺失的签章、周期、双方或费用范围；
- 支持材料问题：按审批后的新类型要求指出缺失的合同/协议、相关文件、活动期照片、POS 或其他证明；
- 金额冲突：逐文件显示合同、审批、结算单中实际识别的金额，禁止只写“不一致”。
