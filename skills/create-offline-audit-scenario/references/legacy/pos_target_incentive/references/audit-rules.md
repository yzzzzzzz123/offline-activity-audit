# POS 达标激励核销规则

## 业务定义

活动期间终端达成预定目标后，在公司级战略渠道或经批准的特殊渠道，按照销售达成比例给予经销商费用支持。激励对象为经销商。满减示例可为全场满 100 减 30，补贴按合同约定的 POS 销售基数乘分档比例返还。

## 必备资料

1. 经销商盖章 POS 数据及逐门店对应的 POS 电子表。
2. 签章促销合同，明确渠道资格、经销商收款主体、活动周期和内容、合格 POS 范围、目标分档、对应比例和上限。
3. 满减活动存在证明：带日期、地址和拍摄时间水印的现场活动照片、小票，或其他能独立证明活动存在的资料。
4. 公司统一模板结算单，列明 POS 基数、命中档位、比例、上限、计算过程和申报金额，并由经销商盖章。

## 权威与金额

- 归档名称和结算单不能替代缺失的签章合同；比例、档位和上限必须以合同为权威。
- 盖章 POS 图片不能替代电子表。两者逐门店和合计销售金额必须一致。
- 按合同活动期和合格范围汇总 POS，选择实际达到的最高目标档位，计算 `合格POS销售金额 × 合同档位比例`，再应用合同上限。
- 结算单申报金额取经销商盖章确认值。全部阻断控制通过且复算金额与申报一致时支持申报；否则支持 0、全额暂缓。
- 人民币按 `ROUND_HALF_UP` 保留两位小数。
