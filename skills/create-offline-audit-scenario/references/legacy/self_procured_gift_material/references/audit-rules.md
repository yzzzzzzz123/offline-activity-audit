# 客户自采赠品物料核销规则

## 业务定义与边界

客户自行采购凳子、收纳篮等物料，在商品促销中赠送消费者。本类型不是终端设计/印刷宣传
单页的物料制作，不是终端制作展架/模型的展示道具，不是公司商品额外搭赠，也不是进场费。

## 必备资料

1. 发票或收据，清楚显示自采物料名称/规格、数量、单价、金额、开票或开具时间等费用明细。
2. 核销资料须明确活动赠送规则，包括购买条件、赠送物料和买赠数量关系。
3. 经销商盖章 POS 数据及与其逐店、逐项对应的 POS 数据电子表。活动返图 Excel 不能替代
   POS 电子表。
4. 所有活动门店在活动期间内的现场水印照片。每张照片自身须清楚显示日期、地址、拍摄时间、
   促销活动内容及客户自采物料；工作簿门店列、文件名和 EXIF 仅用于路由。
5. 公司统一模板结算单，列明物料、数量、单价、计算方式和金额，并由客户/经销商盖章。
6. 签章促销合同，明确经销商、活动周期、活动门店范围、消费者赠送规则、物料、预算及计算
   方式。合同引用的门店附件也必须能由提交资料完整建立。

## 对应与金额

- 合同、结算单、发票/收据的物料、数量、单价和金额须一致；付款记录作为已提交辅助证据时，
  付款合计应与票据/申报一致，付款对象不清楚时不得反向填补票据主体。
- 盖章 POS 与 POS 电子表须在活动周期、门店、销售数量和销售金额上逐项唯一对应，合计一致。
- 活动返图工作簿只负责承载门店与照片路由。每一行必须唯一绑定一张内嵌原图，且照片水印
  门店须与行内门店唯一对应。
- 按赠送规则复核 POS 合格套包数量与自采物料数量。若规则明确每购买一套赠一件，而实际
  自采物料少于合格 POS 数量，须有清楚的限量/先到先得/分配上限条款，否则活动执行不闭环。
- 申报金额以客户盖章结算单为准，并受签章合同预算、有效票据金额和可核验实际采购金额上限
  约束。全部阻断控制通过且复算一致时支持申报，否则支持 0、全额暂缓。
- 人民币按 `ROUND_HALF_UP` 保留两位小数。
