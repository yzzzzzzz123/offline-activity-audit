# 大文件读取边界

使用本Skill固定入口的`--check`读取当前文件、解压及PDF页数安全边界。容量预检不等于所有页面已经读完，真实完成以最终索引和逐页来源为准。

- 依次打开页面、完整成像并释放当页像素对象；不一次渲染全部页面，不靠跳页或抽样省内存。
- 保持既有完整页尺寸与画面质量，文字层只提取一次。照片、表格、印章和页内位置不能因文件大而省去。
- 每页先写临时图像，完整成功后原子发布。磁盘不足或写入失败时不留下可被误用的半张正式页面；已有原件不删除、不改写。
- 加密、损坏、真正页数或像素安全边界，与磁盘、权限及组件故障分别报告。不能把资源错误写成协议未提供，也不能伪造全页读取完成。
- 按原有逐页来源及模型批次继续后续步骤，不把整本PDF文本一次性送入每个阶段；断点恢复仍使用原run和来源校验，不由读取Skill新增核销请求或发送回调。
